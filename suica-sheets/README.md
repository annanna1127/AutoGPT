# Suica 利用履歴をGoogleスプレッドシートに自動記録

iPhone のウォレットで Suica を使う（改札・買い物でタッチする）たびに、
利用先と金額を Google スプレッドシートへ自動で1行追記します。

```
iPhone で Suica をタッチ
  └─ ショートカットの「ウォレット」オートメーションが起動
       └─ Google Apps Script（Web アプリ）へ POST
            └─ スプレッドシート「Suica履歴」シートに追記
```

5分おきに確認しに行く方式ではなく、**使ったその場で記録されます**。
（Suica には公式 API がないため、iPhone ではこの方式が最も確実です）

## 必要なもの

- iOS 17 以降の iPhone（ウォレットに Suica を登録済み）
- Google アカウント

## 手順1: スプレッドシートと Apps Script を用意する（PC推奨）

1. Google スプレッドシートを新規作成します（名前は自由）。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身を全部消し、このフォルダの [`Code.gs`](./Code.gs) の内容を貼り付けて保存します。
4. 関数の選択欄で **`setup`** を選び **実行** します。
   - 初回は権限の確認画面が出るので、自分のアカウントで **許可** します
     （「このアプリは Google で確認されていません」と出たら「詳細」→「〜に移動」）。
   - 実行後、画面下の **実行ログ** に `ショートカットに設定するトークン: xxxxxxxx-...` と表示されます。**このトークンを控えてください。**
   - スプレッドシートに「Suica履歴」シートが作られます。
5. 右上の **デプロイ → 新しいデプロイ** を選びます。
   - 種類の選択（歯車）: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - **デプロイ** を押し、表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）を控えます。

> 「全員」にしても、トークンを知らない人は書き込めません。トークンと URL は他人に教えないでください。

## 手順2: iPhone のショートカットを設定する

1. **ショートカット** アプリ → 下の **オートメーション** → 右上の **＋**。
2. **ウォレット** を選びます。
   - カード: **Suica** を選択（カテゴリはすべて選択のままでOK）
   - **すぐに実行** を選択 → **次へ**
3. **新規の空のオートメーション** を選び、次のアクションを追加します。

   **アクション「URLの内容を取得」**
   - URL: 手順1-5 で控えた **ウェブアプリの URL**
   - 「表示を増やす」をタップ
   - 方法: **POST**
   - 要求本文: **JSON**
   - フィールドを追加（すべて「テキスト」型）:

     | キー | 値 |
     |---|---|
     | `token` | 手順1-4 で控えたトークン |
     | `amount` | 変数「ショートカットの入力」→ タップして **金額** を選ぶ |
     | `merchant` | 変数「ショートカットの入力」→ タップして **加盟店** を選ぶ |
     | `card` | 変数「ショートカットの入力」→ タップして **カード（またはパス）** を選ぶ |
     | `date` | 変数 **現在の日付** |

4. **完了** で保存します。

## 動作確認

- ブラウザでウェブアプリの URL を開き、`{"ok":true,...}` と表示されれば Web アプリは動いています。
- Suica で買い物か改札を通ると、数秒後にスプレッドシートへ行が追加されます。

記録される列:

| 記録日時 | 利用日時 | 利用先 | 金額(円) | カード名 | 元の金額表記 |
|---|---|---|---|---|---|

## うまくいかないとき

- **行が増えない**: オートメーションが「すぐに実行」になっているか、要求本文の `token` が正しいか確認してください。
  ショートカットに「結果を表示」アクションを追加すると、`{"ok":false,"error":"..."}` の内容が確認できます。
- **「kCFErrorDomainCFNetwork エラー -1005」の通知が出る**: 送信中に通信が切れたというエラーです。駅の構内や地下など、電波が不安定な場所でタッチした直後によく起きます。
  まず自宅などの Wi-Fi で、オートメーションの編集画面の **▶（実行）** を押してください。シートに行が増えれば、設定は正しくできています。
  そのうえで「URLの内容を取得」の前に **「待機」アクション（3〜5秒）** を入れると、失敗が減ることがあります。
- **Code.gs を直したのに反映されない**: **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン: 新バージョン** で再デプロイしてください（URL は変わりません）。
- **電車の利用で利用先が空になる/駅名が出ない**: 交通系の取引では、iPhone 側が加盟店名を渡さないことがあります。金額と日時は記録されます。
- **オフライン時**: 通信できないときの利用は記録されません（ショートカットは再送しません）。
- **トークンを作り直したい**: Apps Script の **プロジェクトの設定 → スクリプト プロパティ** で `TOKEN` を削除し、もう一度 `setup` を実行します。

## 制限

- ウォレットのオートメーションが起動した取引だけが記録されます。チャージや、iPhone を持たずにした利用は記録されません。
- 渡される項目（加盟店・金額など）は iOS の仕様に依存し、取引の種類によっては空になることがあります。
