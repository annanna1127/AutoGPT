# アメックス明細CSV → Googleスプレッドシート 自動取り込み

Googleドライブの決まったフォルダにアメックスの明細CSVを入れておくと、1時間ごとに自動でスプレッドシートへ取り込み、月別集計まで更新します。

## できること

- **明細シート**：利用日・利用店名・金額を追記し、日付順に並べ替え
- **重複の除外**：同じ期間のCSVを2回入れても、同じ明細は二重に入りません（同じ日・同じ店・同じ金額の利用が本当に2回あった場合は、2件とも残ります）
- **支払い行の除外**：「お支払いありがとうございます」など、カード代金の引き落とし行は取り込みません（返品・返金のマイナスは残します）
- **月別集計シート**：月ごとの合計金額・件数、利用店別の合計、月別の棒グラフ（明細が増えると自動で更新）
- 取り込み済みのCSVは「取込済み」フォルダへ自動で移動
- 文字コード（Shift_JIS／UTF-8）は自動で判別

## 設定手順（10分くらい）

1. **フォルダを作る**
   Googleドライブに「カード明細CSV」などのフォルダを作り、開いたときのURL `https://drive.google.com/drive/folders/XXXXXXXX` の `XXXXXXXX` 部分（フォルダID）をコピーします。

2. **スプレッドシートを作る**
   新しいGoogleスプレッドシートを作り、メニューの **拡張機能 → Apps Script** を開きます。

3. **スクリプトを貼り付ける**
   最初からある `コード.gs` の中身をすべて消し、このフォルダの `Code.gs` の内容を貼り付けます。
   冒頭の `INBOX_FOLDER_ID: 'ここにフォルダIDを貼り付け'` を、手順1でコピーしたIDに書き換えて保存します。

4. **初回実行**
   上部の関数選択で `setup` を選んで **実行** を押します。
   権限の確認画面が出たら、ご自分のアカウントを選んで許可します（「このアプリは確認されていません」と出たら **詳細 → 安全ではないページに移動** を選びます。自分で作ったスクリプトなので問題ありません）。

これで「明細」「月別集計」シートができ、1時間ごとの自動取り込みが始まります。

## 毎月の使い方

1. アメックスのWebサイト（オンライン・サービス）で明細を **CSV形式** でダウンロード
2. ダウンロードしたCSVを、手順1のフォルダにアップロード（スマホのドライブアプリからでも可）
3. 1時間以内に自動で反映されます。すぐ反映したいときは、スプレッドシートのメニュー **カード明細 → 今すぐ取り込む**

> ドライブの設定で「アップロードしたファイルをGoogleドキュメント形式に変換する」がオンになっていると、CSVがスプレッドシートに変換されてしまい読み込めません。その場合は設定でオフにしてください。

## うまくいかないとき

- **取り込まれない**：Apps Script画面左の「実行数」でエラー内容を確認できます。CSVの見出し行が「ご利用日」「ご利用内容」「金額」と違う名前のときは、`Code.gs` の `DATE_KEYS` / `STORE_KEYS` / `AMOUNT_KEYS` に見出しの名前を追加してください。
- **除外したい行が入る／必要な行が消える**：`CONFIG.EXCLUDE_PATTERNS` を編集します。
- **集計シートの見た目を戻したい**：メニュー **カード明細 → 月別集計シートを作り直す**。
