# かんたん家計簿（Google Apps Script 版）

スマホで使える家計簿Webアプリです。データは自分の Google スプレッドシートに、レシート画像は Google ドライブに保存されます。

| やりたいこと | できること |
|---|---|
| ① クレカ・口座・Suica・PayPay の自動反映 | **Gmail の利用通知メールを1時間ごとに自動取込**（クレカ・銀行）／**履歴画面のスクショ取込**（PayPay・Suica）／**明細CSVをそのまま取込**（列の形式は自動判別） |
| ② レシート撮影で自動入力 | 撮るだけで **店舗・金額・日付・勘定科目・支払方法** を自動入力。画像はドライブの `家計簿レシート/2026-10/` のような**月ごとのフォルダに自動仕分け** |
| ③ 手入力 | 金額 → 科目をタップ → 記録、の3タップ |
| ④ スプレッドシートへの反映 | データそのものがスプレッドシートに保存されるので常に一致。「月次集計」「科目別集計」シートも自動で更新 |

二重計上の防止：カードで払ってレシートも撮った場合は、同じ日付・金額のカード明細にレシートの店舗名・科目・画像を**紐づけて1件にまとめ**ます。チャージ・口座振替・カード代金の引き落としは自動で除外します。

## 「マネーフォワードのようなAPI連携」について（正直な説明）

マネーフォワードは、銀行やカード会社と個別に契約したうえで、国に登録された事業者（電子決済等代行業者）として口座データを取得しています。**個人が自分用のアプリから同じ方法で接続することは、現状できません。** PayPay・Suica も、個人が自分の利用履歴を取得できる公開APIはありません。

そこでこのアプリでは、個人でも使える次の3つの方法で「ほぼ自動」にしています。

1. **クレジットカード・銀行** → 各社の「利用通知メール」をオンにしておくと、Gmail から自動で取り込みます（設定後は何もしなくてOK）。
2. **PayPay・Suica** → アプリの利用履歴画面をスクショして「スクショ取込」。1枚に何件写っていてもまとめて登録できます。
3. **月ごとの明細CSV** → カード会社・銀行のサイトや PayPay アプリからダウンロードしたCSVを選ぶだけ（Shift_JIS にも対応）。

## 必要なもの

- Google アカウント（Gmail・ドライブ・スプレッドシート）
- Claude API キー（レシートやメールの読み取りに使用）: https://console.anthropic.com/ で発行します。
  - 料金の目安：レシート1枚あたり数円程度（従量課金）。読み取り用のモデルは `src/Config.gs` の `MODEL` で変更できます。

## セットアップ（15分くらい）

### 1. Apps Script プロジェクトを作る

**方法A：コピー&ペースト（かんたん）**

1. https://script.google.com/ で「新しいプロジェクト」を作り、名前を「家計簿」にする。
2. `src/` フォルダの各ファイルを同じ名前で作成し、中身を貼り付ける。
   - `.gs` ファイル → 左の「ファイル ＋」→「スクリプト」（拡張子 `.gs` は自動で付きます）
   - `index.html` → 「ファイル ＋」→「HTML」で `index` という名前で作成
3. 「プロジェクトの設定（⚙）」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」をオンにして、`src/appsscript.json` の内容で上書きする。

**方法B：clasp（コマンドラインに慣れている方）**

```bash
npm install -g @google/clasp
clasp login
cd kakeibo
clasp create --type standalone --title 家計簿 --rootDir src
clasp push
```

### 2. Claude API キーを設定

「プロジェクトの設定（⚙）」→「スクリプト プロパティ」→「プロパティを追加」

- プロパティ：`ANTHROPIC_API_KEY`
- 値：発行した API キー

### 3. setup を実行

エディタ上部の関数選択で `setup` を選んで「▶ 実行」。初回は権限の確認が出るので許可します（「このアプリは Google で確認されていません」と出たら「詳細」→「家計簿（安全ではないページ）に移動」。自分で作ったスクリプトなので問題ありません）。

これで次のものが作られます。

- スプレッドシート「家計簿」（取引・勘定科目・連携設定・月次集計・科目別集計）
- ドライブのフォルダ「家計簿レシート」
- Gmail のラベル「家計簿/取込済」
- Gmail を1時間ごとに取り込む自動実行の設定（トリガー）

### 4. Webアプリとして公開

「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」

- 次のユーザーとして実行：**自分**
- アクセスできるユーザー：**自分のみ**（家計のデータなので必ず「自分のみ」に）

表示された URL をスマホで開き、共有メニューから「ホーム画面に追加」するとアプリのように使えます。

> コードを変更したら「デプロイを管理」→ 編集 →「新バージョン」で更新します。

### 5. 利用通知メールの取込を設定

1. 使っているカード会社・銀行のサイトで「カード利用のお知らせ」「入出金通知」メールをオンにする。
2. スプレッドシートの「連携設定」シートで、届いたメールに合わせて「Gmail検索条件」を書き、「有効」にチェック。
   - 例の条件は目安です。実際のメールを Gmail で検索して、ヒットする条件（`from:差出人` や `subject:件名の一部`）にしてください。
3. アプリの「連携」タブ →「今すぐ取り込む」で動作確認。以降は1時間ごとに自動で取り込みます。

## カスタマイズ

- **勘定科目**：スプレッドシートの「勘定科目」シートで追加・変更できます（種別は「支出」か「収入」）。AIの自動分類もこの一覧から選ばれます。
- **支払方法**：`src/Config.gs` の `PAYMENT_METHODS`。

## ファイル構成

```
src/
  appsscript.json  権限・Webアプリの設定
  Config.gs        設定値（モデル・シート名・既定の科目など）
  Setup.gs         初期セットアップ（setup 関数）
  Code.gs          Webアプリの入口と画面から呼ぶ関数
  Transactions.gs  取引の登録・編集・削除・集計、重複チェック
  Claude.gs        Claude API での読み取り（構造化出力でJSONを取得）
  Importers.gs     レシート/スクショ・Gmail・CSV の取込
  Drive.gs         レシート画像を月別フォルダへ保存
  index.html       スマホ向けの画面
```

## 制限・注意

- Apps Script は1回の処理が最大6分です。数百行ある大きなCSVは月ごとなどに分けて取り込んでください。
- 読み取り結果は保存前に確認画面が出るので、間違いがあればその場で直せます。
- レシート画像・メール本文は読み取りのために Claude API（Anthropic）へ送信されます。
