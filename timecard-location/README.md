# 勤怠・位置記録アプリ（同意ベース）

従業員・業務メンバーの**勤務時間中だけ**、**本人の操作で**位置を記録し、
Google スプレッドシートに蓄積する小さな Web アプリです。移動経路・滞在時間・
（任意で）住所を集計できます。

> **大前提**
> このアプリは「本人が入っていることを知っていて、同意していて、いつでも止められる」
> 使い方のために作られています。相手に知らせず・同意なく位置を追跡する用途には
> 使わないでください。日本ではストーカー規制法・個人情報保護法などに触れるおそれが
> あり、違法です。

## できること

- 本人が「勤務開始」を押した時だけ記録開始、「勤務終了」で完全停止
- 勤務中は一定間隔（既定5分）で現在地を記録
- 記録中は画面上部に**常時バナー**、送信内容も本人に一覧表示（隠れて動かない）
- 記録先は **Google スプレッドシート**（Apps Script 経由／サーバー不要）
- 集計: セッションごとの勤務時間・総移動距離・**滞在地点と滞在時間**（＝移動経路の要約）
- 任意: 逆ジオコーディングで**住所**を併記（既定OFF）

## 構成

```
timecard-location/
├─ index.html              本体（本人が開く画面）
├─ app.js                  本体のロジック
├─ styles.css              スタイル
├─ apps-script/Code.gs     スプレッドシート側のバックエンド（貼り付け用）
├─ CONSENT_TEMPLATE.md     従業員向けの説明・同意書のひな形
└─ README.md
```

## セットアップ

### 1. スプレッドシート側（記録先）

1. Google スプレッドシートを新規作成する。
2. **拡張機能 → Apps Script** を開き、`apps-script/Code.gs` の中身を貼り付けて保存。
3. **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**
   - 実行ユーザー: **自分**
   - アクセスできるユーザー: **全員**（本人の端末から送信できるように）
4. 発行された `https://script.google.com/macros/s/.../exec` の URL を控える。

### 2. 本体（Web アプリ）

位置情報の取得には **HTTPS** が必要です（`localhost` は例外）。次のいずれかで配信します。

- GitHub Pages / Netlify / Cloudflare Pages などに `index.html` / `app.js` / `styles.css` を置く
- 動作確認だけなら手元で:
  ```bash
  cd timecard-location
  python3 -m http.server 8000
  # ブラウザで http://localhost:8000 を開く
  ```

### 3. 初回設定（本人の端末で）

1. アプリを開き、控えた **記録先 URL**、**従業員ID／氏名**、記録間隔を入力。
2. 同意画面の内容を確認し、チェックして「同意して勤務開始」。
3. ブラウザが位置情報の許可を求めたら許可する。

## 集計（滞在時間・移動経路）

スプレッドシートのメニュー **「勤怠集計 → 日次サマリーを作成」** を実行すると、
`サマリー` シートに次が出力されます。

| 列 | 内容 |
|----|------|
| 勤務開始／終了／勤務時間(h) | セッション（開始〜終了）の時刻と長さ |
| 記録点数 | そのセッションで記録した地点の数 |
| 総移動距離(km) | 記録点をつないだ概算距離（＝移動経路の長さ） |
| 滞在地点数 | 半径150m・5分以上とどまった地点の数 |
| 滞在内訳 | 「住所または座標 : 滞在分」の一覧 |

しきい値（`STAY_RADIUS_M` / `STAY_MIN_MINUTES`）は `Code.gs` の冒頭で調整できます。

## 住所（逆ジオコーディング）について

設定で「住所も記録する」をONにすると OpenStreetMap / Nominatim で住所を付与します。
**Nominatim は本番の大量利用に不向き**（1 req/s 上限・商用制限あり）です。恒常運用では
Google Maps Platform や Mapbox など正規サービスへ `app.js` の `reverseGeocode()` を
差し替えてください。

## プライバシー運用の注意

- 記録データは個人情報です。**閲覧権限・保管期間・利用目的**を勤務先の規程に従って管理してください。
- アクセス「全員」のウェブアプリは URL を知る人が POST できます。必要なら
  `Code.gs` に共有トークン検証を足し、本体からも同じ値を送るよう改修してください。
- 従業員への事前説明・同意取得には `CONSENT_TEMPLATE.md` を活用してください。

## 設計上あえてそうしていること

- **勤務中にページをリロードしても自動で記録再開しません。** 本人がもう一度「勤務開始」を
  押す必要があります。バックグラウンドでこっそり継続しない＝同意と透明性を最優先するためです。
- 設定・ログ・未送信キューは**その端末の localStorage** にのみ保持します。
