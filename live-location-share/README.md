# 現在地リンク共有（ゼンリー風・シンプル版）

**自分の現在地**を、リンクを渡した相手にだけ地図でリアルタイムに見せる小さな Web アプリです。
LINE や Google マップの「現在地を共有」に近い、いちばんシンプルなモデルです。

> このアプリで共有されるのは**使う本人の現在地**です。相手の居場所を本人に無断で
> 追跡する用途には使えません（そうした使い方は作っていません）。

## 特徴（ゼンリーの「安全な部分」を踏襲）

- **自分が「共有ON」の間だけ**位置を送信。許可しなければ何も起きない
- 共有中は画面に**常時バナー**、**停止ボタン**、**自動期限**（1/4/8時間）
- **タブを閉じると送信も停止**（裏で動き続けない）→ 相手の画面も「共有終了」になる
- リンクを開いた相手は**地図でリアルタイム表示**（現在地・精度・直近の移動経路）
- 相手は**設定不要**（リンクに全部入っている）／地図の API キーも不要（OpenStreetMap）

## 構成

```
live-location-share/
├─ index.html   共有する人のページ
├─ share.js
├─ view.html    リンクを開く人の地図ページ（Leaflet）
├─ view.js
├─ styles.css
└─ apps-script/Share.gs   現在地を一時保存する小さなバックエンド
```

## セットアップ

### 1. バックエンド（1回だけ）

1. Google スプレッドシートを新規作成 → **拡張機能 → Apps Script**。
2. `apps-script/Share.gs` を貼り付けて保存。
3. **デプロイ → 新しいデプロイ → ウェブアプリ**（実行: 自分／アクセス: 全員）。
4. 発行された `.../exec` の URL を控える。
5. （任意）`cleanup` をトリガーに設定すると、停止・期限切れデータを自動削除します。

### 2. ページを配信

位置情報には **HTTPS** が必要です（`localhost` は例外）。

- GitHub Pages / Netlify などに `live-location-share/` の中身を置く、または
- 手元で確認: `cd live-location-share && python3 -m http.server 8000` → `http://localhost:8000`

### 3. 使い方

1. 共有する人が `index.html` を開き、初回だけ **共有先 URL** と **表示名** を設定。
2. 共有時間を選んで「**現在地の共有を開始**」→ 位置情報を許可。
3. 表示された**リンクをコピーして相手に送る**。
4. 相手がリンクを開くと、地図に現在地がリアルタイム表示される。
5. 「**共有を停止**」または期限で終了。相手の画面は「共有終了」になる。

## リンクの形

```
.../view.html?e=<共有先URL>&id=<共有ID>
```

共有IDは開始ごとにランダム生成されます。停止・期限切れ後は同じリンクでも見えません。

## カスタマイズ

- 送信間隔: `share.js` の `SEND_INTERVAL_MS`（既定8秒）
- 更新間隔（閲覧側）: `view.js` の `POLL_MS`（既定8秒）
- 経路の保持点数: `Share.gs` の `TRAIL_MAX`（既定30点）

## プライバシー運用の注意

- 共有先スプレッドシートには現在地が一時保存されます。閲覧できる人を絞り、不要になったら
  `cleanup` などで削除してください。
- アクセス「全員」のウェブアプリは URL を知る人が読み書きできます。共有IDはランダムですが、
  より厳密にするなら `Share.gs` に共有トークン検証を足してください。
